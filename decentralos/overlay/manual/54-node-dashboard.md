# The Node Dashboard

The dashboard is where you see how your node is doing. It opens full-screen every time DecentralOS starts, so a DecentralOS computer with a screen shows it all day. If you closed it, open it again by clicking the node icon in the top bar, from the app launcher (DecentralChain Node), or with `decentralos-node open` in a terminal.

The same dashboard opens on your phone once you [pair it](55-phone-pairing.md).

## At the top: what needs attention

The first thing on the dashboard is a one-line summary: "Your node is running and up to date", "Your node is catching up", "Your node is starting" or "Your node is not running". Below it, any problem is listed with what to do about it. When everything is fine, it says so: "Everything is working. There is nothing you need to do."

## Network status

The current block your node has reached, and how many other nodes it is connected to. While the node is catching up, a progress bar shows how much of the blockchain it has downloaded so far.

## Your wallet

The node wallet's DCC balance and address, with a QR code for the address so a phone wallet can send to it, and the "Show my 15 recovery words" button. See [Wallet & Recovery Phrase](53-wallet-and-recovery-phrase.md).

## Earning rewards

How much stake your node has, out of the 1,000 DCC it needs to take part in creating blocks. Once it has enough, this section says "Your node has enough stake and takes part in creating blocks." See [earning rewards](52-your-decentralchain-node.md#earning-rewards).

## The DecentralChain network

The latest blocks and transactions on the DecentralChain network, read from the public Mainnet node. It's shown even while your own node is still catching up or starting, so you always see what the network is doing.

## Use your phone

A QR code that pairs your phone with the node. See [Phone Pairing](55-phone-pairing.md).

## Network

How the computer is connected: by cable, by Wi-Fi, or not at all, and its address on your network. On the box's own screen you can join a Wi-Fi network here: choose it, enter its password and press "Join Wi-Fi". A cable from your router is the most reliable connection and needs no setup at all.
